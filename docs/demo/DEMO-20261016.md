## Roteiro de cinco minutos

1. **Problema (30 s):** explique que a descrição natural será convertida em uma proposta revisável; ainda não é executável nem publicável.
2. **Abrir sessão (30 s):** selecione a sessão fixture homologada na lista recente do navegador ou recupere-a pela API.
3. **Mostrar a proposta (60 s):** abra a sessão fixture previamente homologada abaixo. Explique claramente que esta proposta é simulada. Não gere outra resposta real.
4. **Inspecionar BPMN (60 s):** mostre funcionário → análise do gestor → XOR “Compra aprovada?”; um ramo segue para o financeiro e o outro termina reprovado.
5. **Inspecionar formulários (60 s):** mostre o campo Material solicitado e o campo booleano Decisão do gestor.
6. **Persistir (45 s):** mostre a revisão já aceita, recarregue a página e confirme que ela e os artefatos voltam da API.
7. **Fechar (15 s):** destaque validação determinística de referências, tipos e estrutura. Papéis sem vínculo de runtime ficam como pendência; nenhuma integração de negócio é executada.

Texto sintético R01 usado na homologação (não reenviar nesta demonstração):

## Limitações para explicar

- JSON Object Mode não garante schema nem semântica. As duas tentativas R01 retornaram JSON; falharam em validações GraphIR e não persistiram proposta real. Os defeitos foram diagnosticados com captura temporária sintética, removida depois. O smoke strict anterior recebeu HTTP 400 em `response_format`. Consulte o [relatório final](../../../exports/PROCESS-AI-FINAL-20261015.md) e o [relatório do hotfix](../../../exports/PROCESS-AI-HOTFIX-P0-20261015.md).
- A geração controlada suporta a projeção atual: nós start/end/tarefa humana/XOR, condições atômicas e generic-bpmn2. Integrações declarativas não são oferecidas nesse caminho.
- Papéis sem vínculo autorizado geram prévia `needs-input`; publicação permanece bloqueada até resolução.
- Refinamentos continuam usando o pipeline ProcessSpec anterior. GraphPatch, FormPatch e chunking não estão implementados.
- É uma prévia revisável: sem publicação, execução BPMN ou efeitos em sistemas de negócio.

## Última homologação R01 — preparar, não executar sem autorização

O Ledger cumulativo local foi conferido: 2 chamadas, 10.231 tokens reais, nenhuma reserva pendente; o limite histórico desta janela era 3 chamadas. Preserve o arquivo em `%LOCALAPPDATA%\ProcessAI\diagnostics\mvp-20261015-groq-budget.json`. O comando abaixo mantém o limite de 1 chamada no processo e usa o ledger cumulativo com teto 3 para impedir uma segunda chamada após reinicialização. Não o apague nem zere. A chamada só deve ocorrer após autorização explícita.

Terminal 1 — nova API a partir do código TypeScript atual, porta 3336. Abre uma janela PowerShell dedicada; overrides ficam nela e não alteram `.env`:

```powershell
cd D:\dev\Process\process-ai-backend
$line = Get-Content .env | Where-Object { $_ -match '^DATABASE_URL=' } | Select-Object -First 1
$databaseUrl = $line.Substring('DATABASE_URL='.Length).Trim('"')
$database = [uri]$databaseUrl
if ($database.Host -ne '127.0.0.1' -or $database.Port -ne 55432 -or $database.AbsolutePath.TrimStart('/') -ne 'processai_v2c1') { throw 'Banco não é o descartável homologado' }
$settings = @{}
Get-Content .env | ForEach-Object { if ($_ -match '^([^#=]+)=(.*)$') { $settings[$matches[1]] = $matches[2].Trim('"') } }
if (!$settings['EXTERNAL_AI_BASE_URL'] -or !$settings['EXTERNAL_AI_API_KEY'] -or !$settings['AI_MODEL']) { throw 'Configuração do provider incompleta no .env; valores não são exibidos' }
$env:DATABASE_URL = $databaseUrl
$env:PORT = '3336'
$env:CORS_ORIGIN = 'http://localhost:5176'
$env:AI_PROVIDER = 'openai-compatible'
$env:EXTERNAL_AI_APPROVED = 'true'
$env:EXTERNAL_AI_STRUCTURED_OUTPUT = 'json-object'
$env:AI_GRAPH_IR_MODE = 'controlled'
$env:AI_SEMANTIC_GROUNDING_MODE = 'controlled'
$env:AI_MAX_PROVIDER_CALLS = '1'
$env:AI_MAX_PROVIDER_TOKENS = '24000'
$env:AI_MAX_CUMULATIVE_PROVIDER_CALLS = '3'
$env:AI_PROVIDER_BUDGET_LEDGER_PATH = Join-Path $env:LOCALAPPDATA 'ProcessAI\diagnostics\mvp-20261015-groq-budget.json'
$env:AI_MAX_OUTPUT_TOKENS = '8192'
$env:AI_TIMEOUT_MS = '180000'
node --env-file-if-exists=.env --import tsx src/server.ts
```

O provider deve registrar zero retries; o adaptador está construído com `maxRateLimitRetries=0`. Abra a API somente depois da autorização. Terminal 2 — exatamente um POST de geração R01; a criação do projeto não chama provider:

```powershell
$project = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:3336/api/v1/projects' -ContentType 'application/json' -Body (@{ name = 'R01 sintético final'; targetProfile = 'generic-bpmn2' } | ConvertTo-Json)
$body = @{ text = 'Um funcionário solicita compra de material. O gestor analisa a solicitação. Se aprovar, o financeiro recebe para providenciar a compra. Se reprovar, o processo termina.'; baseRevision = 0; dataClassification = 'synthetic' } | ConvertTo-Json
$response = Invoke-WebRequest -SkipHttpErrorCheck -Method Post -Uri "http://127.0.0.1:3336/api/v1/design-sessions/$($project.sessionId)/messages" -ContentType 'application/json' -Body $body
$result = $response.Content | ConvertFrom-Json
[pscustomobject]@{ HttpStatus = $response.StatusCode; Code = $result.code; GenerationRunId = $result.generationRunId; Status = $result.status }
if ($result.generationRunId) {
  $run = Invoke-RestMethod -Uri "http://127.0.0.1:3336/api/v1/generation-runs/$($result.generationRunId)"
  $run.metrics.pipeline | Where-Object { $_.stage -eq 'graph-ir-validation' } | ConvertTo-Json -Depth 8
}
```

Se falhar, encerre a execução e não repita. O erro inclui `generationRunId`; `GET /api/v1/generation-runs/{id}` retorna os diagnósticos estruturais/semânticos/cobertura sanitizados persistidos. O workspace da UI não retorna os detalhes do payload e a revisão atual fica preservada.
